 # Amazon Prime Video Data Analysis – Power BI

## 📊 Project Overview

This project analyzes Amazon Prime Video titles using Power BI. The dashboard provides insights into movies, TV shows, genres, ratings, release years, countries, and content distribution.

## 🛠️ Tools & Technologies

* Power BI
* CSV Dataset
* Data Cleaning & Transformation
* Data Visualization
* DAX

## 📁 Files

* `amozon_prime.pbix` – Power BI dashboard file
* `amazon_prime_titles(1).csv` – Dataset used for analysis

## 📈 Dashboard Insights

* Total Movies and TV Shows
* Content by Genre
* Content by Release Year
* Ratings Analysis
* Country-wise Content Distribution
* Movie vs TV Show comparison

## 🎯 Objective

The main objective is to analyze Amazon Prime Video content and create an interactive dashboard that helps users understand content trends and distribution.
